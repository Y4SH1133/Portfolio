## ✨ Key Features

- **Pill-shaped Glassmorphic Navbar:** Fixed, blurred navigation bar with smooth hover underlines and quick anchor routing.
- **Interactive Terminal UI:** Simulated developer command prompt window displaying quick info and skill sets.
- **Infinite Tech Marquee:** Seamless, infinite horizontal sliding animation showcasing core programming languages and tools.
- **Modern Typography & Layouts:** Editorial-inspired typography with bold statement blocks (`VISION`, `INTENTION`) and responsive grid structures.
- **Project Showcase Cards:** Clean cards highlighting project summaries, tech tags, and links to live demos and source code.
- **Mobile Responsive:** Fluid layout optimized for mobile screens, tablets, and wide desktop displays.

## 🚀 Getting Started

To run or customize this portfolio locally on your machine, follow these steps:

### 1. Clone the Repository
```bash
git clone https://github.com/Y4SH1133/portfolio.git
cd portfolio
```

### 2. Run Locally
Because this project uses vanilla HTML, CSS, and Tailwind via CDN, no package installations or build steps are required.

- **Option A (Browser directly):** Double-click `index.html` or drag it into any modern web browser.
- **Option B (VS Code Live Server):**
  1. Open the folder in VS Code.
  2. Right-click `index.html` and select **"Open with Live Server"**.
